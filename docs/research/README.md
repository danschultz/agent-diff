# Research

Each file records research into a question: the findings, the options they
suggest, and what couldn't be checked. Research doesn't propose or decide
anything. Choices are recorded as [decisions](../decisions/README.md). See
[`.rules/research.md`](../../.rules/research.md) for how to add research. Terms
are defined in the [glossary](../glossary.md).

| Research                                                                                                                                   | Summary                                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [0001: How should the project board stay up to date?](0001-keeping-the-project-board-up-to-date.md)                                        | GitHub's built-in workflows can't set Status from labels, so keeping the board in sync with the `agent:*` labels needs a GitHub Actions workflow, `implement` setting Status as it moves labels, or `implement` reconciling the board on each tick.                                                                                                                                                                   |
| [0002: Which React state management library fits the review UI?](0002-react-state-management.md)                                           | Compared plain React and ten libraries for the review UI's state on size (0 to 13.6 KB gzipped), type safety, code for the same drafts example (15 to 45 lines), maintenance, agent-friendliness, and server-pushed updates, with all examples type-checked and run on React 19.                                                                                                                                      |
| [0003: How do Zustand and TanStack Store work with Immer, and which stores infer their own types?](0003-immer-and-inferred-store-types.md) | Zustand needs a declared type or `combine` to infer its store's type, while TanStack Store and five other libraries infer it; Immer works with both, and a `createImmerStore` helper for TanStack Store makes `tsc` reject mutating read state.                                                                                                                                                                       |
| [0004: Which TypeScript CLI libraries could build the `agent-diff` CLI?](0004-typescript-cli-libraries.md)                                 | Of 20 CLI libraries checked, 17 were used to write the same example CLI: small typed parsers such as Commander, Stricli, and Crust start near the `parseArgs` baseline but only expose a full or machine-readable reference through APIs or build steps, while agent-oriented frameworks such as incur and Padrone print one from the CLI itself at the cost of 15 MB or more and about three times the startup time. |
| [0005: Could `implement` move to GitHub Actions and Claude Code on the web?](0005-moving-implement-off-the-server.md)                      | GitHub Actions can start and resume briefs on events but loses Remote Control and push notifications, Claude Code on the web keeps answering in the Claude app and follows pull requests with auto-fix but can't start from an issue label, a workflow firing a Routine covers the start, and a self-hosted runner removes polling while keeping the server.                                                          |
