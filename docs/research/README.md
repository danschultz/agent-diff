# Research

Each file records research into a question: the findings, the options
considered, and a proposed approach. Research proposes. A
[decision](../decisions/README.md) settles. See
[`.rules/research.md`](../../.rules/research.md) for how to add one. Terms
are defined in the [glossary](../glossary.md).
